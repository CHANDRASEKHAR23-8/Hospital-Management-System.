# Hospital Patient Record Management System

## Project Description
A web-based Hospital Patient Record Management System developed using Java JSP, Servlets, Oracle Database 10g, and CSS.

## Technologies Used
- Java 25
- JSP and Java Servlets
- Apache Tomcat 9
- Oracle Database 10g
- HTML and CSS
- Eclipse IDE

## Features
- Add patient records
- View patient records
- Update patient details
- Delete patient records

## Setup
1. Import the project into Eclipse.
2. Configure Apache Tomcat 9.
3. Configure Oracle Database and the database connection.
4. Deploy the project to Tomcat.
5. Open `http://localhost:8086/Hospital/` in your browser.
